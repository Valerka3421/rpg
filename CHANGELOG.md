# Changelog

Все значимые изменения в проекте «Этельгард» документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
и проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Added
- Полноценный порт игры на C# с использованием фреймворка MonoGame.
- Процедурная генерация графики и звукового сопровождения.
- Модульные тесты на xUnit для ключевых систем (генерация, игровая логика).
- Файл решения `.sln` для удобной работы в Visual Studio и Rider.
- `global.json` для фиксации версии .NET SDK.
- CI-пайплайн GitHub Actions для сборки и тестирования C#-проекта.
- Английская версия README (в разработке).

### Changed
- Архитектура проекта полностью переработана под C# и MonoGame.
- Документация (`CONTRIBUTING.md`, `README.md`) обновлена с учётом нового стека.
- Скрипты сборки и запуска заменены на команды .NET CLI.

### Removed
- Зависимости от Python (Pygame, pytest, ruff, black, mypy и т.п.).
- Файлы конфигурации Python: `.coveragerc`, настройки `pyproject.toml`.
- Устаревшие записи в CHANGELOG, относящиеся к Python-версии.
- Неиспользуемые ассеты (при наличии).

### Fixed
- Исправлены ошибки, связанные с кроссплатформенностью (Windows/Linux/macOS).
- Устранены проблемы с производительностью процедурной генерации.

## [2.0.0] - 2026-11-20

### Added
- Первый стабильный релиз C#-версии «Этельгард» на MonoGame.
- Базовый игровой цикл, генерация мира, система навыков.
- Настроена сборка под Windows, Linux и macOS.

### Changed
- Проект переведён с Python/Pygame на C#/MonoGame.
- Все игровые системы переписаны с сохранением игрового дизайна.

### Removed
- Поддержка Python-версии прекращена.
