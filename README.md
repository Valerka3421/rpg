# Этельгард

Тайловая RPG на Python + pygame-ce: открытый мир, 20 этажей процедурного
подземелья, четыре босса, инвентарь с редкостями, крафт, магазин, квесты,
статус-эффекты, перки-книги и кооперативный режим до 4 игроков по локальной
сети.

Вся графика — процедурная (PNG в `assets/sprites/` необязательны, но проходят
ту же цветокоррекцию), звуки синтезируются на лету. Палитра выдержана в духе
Stoneshard: тёплый почти-чёрный камень, приглушённая олива, холодный
сине-зелёный сумрак и янтарный свет факелов.

## Как рисуется мир

Тайлы ([render/tiles.py](render/tiles.py)) — не «прямоугольники в кадре», а
готовые поверхности 64×64 с деталями: каменная кладка с раствором,
выщербленными углами и трещинами; плиты пола со швами, мхом и лужами;
факелы с тёплым ореолом; лестницы вниз/вверх; арка выхода с дневным светом;
трава с цветами, камнями и проплешинами; деревья с объёмной кроной. Вариант
тайла выбирается по координате детерминированным хэшем — мир стабилен, но
не повторяется.

Поверхность — стартовая деревня Этельгард в центре карты 100×70 и восемь
разных лесных краёв вокруг: сосновый бор, берёзовая роща, каменный перевал,
осенний лес, гиблое болото, дремучий ельник, цветущая поляна и мёртвый лес.
Раскладка ([core/overworld.py](core/overworld.py)) общая для одиночной и
сетевой игры. Вход в подземелье стоит на Каменном перевале (северо-восток)
и окружён руинами: рунический пол, сломанные колонны и валуны.

Свет запекается в тайл по расстоянию до игрока (радиальное затухание к краю
видимости), у основания стен лежит мягкая контактная тень. Всё это
кэшируется: карта перерисовывается только при шаге или смене этажа, поэтому
кадр стоит ~1.2 мс.

Спрайты ([render/icon_renderer.py](render/icon_renderer.py)) проходят общий
финиш ([render/textures.py](render/textures.py)): обесцвечивание, тёплый верх
и холодный низ, обводка, мягкая тень. PNG при загрузке приводятся к той же
палитре, а не остаются яркими пятнами. Тайлы, спрайты и свет используют общие
примитивы: детерминированный шум, оттенки, бевелы, силуэты.

## Установка и запуск

```bat
python -m pip install -r requirements.txt
run.bat
```

`run.bat` сам найдёт `Aethelgard.exe`, виртуальное окружение или системный
Python. Альтернатива — `python main.py`.

Сборка standalone-версии (нужен PyInstaller):

```bat
build.bat
```

Результат — `dist\Aethelgard.exe` (Python внутри).

## Тесты

```bat
python -m pip install -r requirements-dev.txt
test.bat
```

`test.bat` пробует pytest в `.venv`, затем в системном Python.
395 тестов: правила боя, лут, квесты, сейвы, генерация мира, процедурные
текстуры, сетевой сервер, клиентская интерполяция и регрессии на исправленные
баги.

## Управление

| Клавиши | Действие |
|---|---|
| `W A S D` / стрелки | шаг |
| `Пробел` | удар по ближайшему врагу |
| `I` | инвентарь-сетка (`1–9` — использовать, `Q/E` — страницы, `U/V` — снять экипировку) |
| `C` | характеристики (`1–5` — вложить очко) |
| `K` | крафт (`1–8` — создать) |
| `L` | квесты (`Enter` — взять/сдать) |
| `T` | диалог с NPC / магазин |
| `H` | быстрое зелье |
| `M` | мини-карта |
| `Tab` | статистика забега |
| `F5` / `F9` | сохранить / загрузить |
| `Esc` | меню / закрыть окно |
| Колесо / `PageUp` / `PageDown` | прокрутка лога боя |
| `Y` (мультиплеер) | чат: ввод, `Enter` — отправить, `Esc` — отмена |

В магазине: `S` — режим покупки/продажи, `R` — обновить товар,
`Q/E` — страницы; покупка и продажа — кликом по предмету. Лестницы: `↓` — глубже,
`↑` — на этаж выше, на глубине 1 находится выход на поверхность.

  data.py          монстры, предметы, классы, дроп, кривая опыта
  rules.py         ОБЩИЕ правила: бой, лут, статусы, опыт, крафт, спавн
  entities.py      Player / Entity / Dungeon
  world.py         генерация мира, FOV, BFS
  overworld.py     раскладка деревни, биомов, дорог и руин
  save.py          (де)сериализация, слоты, кэш этажей
  quests.py        журнал квестов
game/              одиночная игра
  game.py          состояние, движение, бой, сохранения, ввод
  *_controller.py  меню, диалоги, квесты, магазин, крафт, статистика
render/            отрисовка
  textures.py      общие примитивы: шум, обводка, тени, свет
  tiles.py         процедурные тайлы и их кэш
  theme/sprites/…  тема, рендереры, процедурные иконки

### Ключевое правило архитектуры

Одиночная игра (`game.Game`) и сервер (`net.core.GameCore`) **не дублируют
правила**: урон, крит, уворот, статусы, награды за убийство, подбор лута,
крафт, опыт и поиск свободной клетки живут в `core/rules.py`. UI-слой
(логи, звук, всплывающие цифры) остаётся в игре.

Разрешение хранится только в `core.config`; рендереры читают `config.SCREEN_W`
в момент отрисовки, поэтому смена размера окна не требует синхронизации
копий констант.

### Формат сохранений

JSON, `version: 6`. Тайлы карт пишутся компактными строками цифр
(`"011001..."`), текущий этаж не дублируется в кэше этажей — сейв середины
подземелья занимает ~100 КБ вместо ~580 КБ. Сейвы версии 5 читаются
(старый формат тайлов и экспоненциальная кривая опыта мигрируют
автоматически). Слишком новый сейв отклоняется, а не ломает игру.

### Кооператив

Хост: меню → «Мультиплеер» → «Создать игру» (порт 9000). Клиент: «Присоединиться»
→ IP хоста. Сервер авторитетен: клиент только шлёт ввод и рисует снапшоты.
Игрок привязан к файлу-токену в домашнем каталоге (`~/.ethelgard_player_id`),
поэтому прогресс восстанавливается при переподключении. «Сохранить мир» в
паузе (хост) плюс автосейв при выходе последнего игрока.

В кооперативе есть общий **лог боя** (убийства, уровни, подбор, покупки,
переходы между этажами) и **чат** на `Y`. Позиции игроков и мобов
интерполируются между снапшотами (20 Гц → плавные 60 fps), а на мини-карте
сокомандники видны всегда — как радар отряда, даже вне поля зрения.

Ограничения кооператива: квесты пока одиночные, смерть — респавн на этаже.
Диалоги с NPC работают: `T`/`Enter` рядом со старейшиной на поверхности или
с торговцем в подземелье открывает диалог, откуда доступны реплики и торговля.

### Производительность

Рендер кэширует всё, что не меняется каждый кадр: отрендеренный текст,
градиент меню, кнопки, слой карты, основу мини-карты и тайлы.

| Что | Значение |
|---|---|
| кадр игрового поля | ~1.3 мс (1280×720), ~1.8 мс (1920×1080) |
| модалки (инвентарь/статы) | ~3.5 мс (было 12.7 мс) |
| меню | ~0.4 мс (было 5.7 мс) |
| перерисовка карты при шаге | ~4.4 мс (1280), ~7.4 мс (1920) |
| старт игры (сборка тайлов и градиента заранее) | ~200 мс один раз |

## Ассеты

`assets/sprites/structure.txt` — список опциональных PNG. Если файла нет,
рисуется процедурный вариант. `assets/sounds/*.wav` перекрывают
синтезированные звуки.
