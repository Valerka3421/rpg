# 🎮 Этельгард (Aethelgard)

Тайловая RPG с процедурной генерацией, написанная на C# с использованием MonoGame. Порт оригинальной Python/Pygame-версии.

---

## 📖 О проекте

**Этельгард** — это RPG с открытым миром, процедурным подземельем и кооперативным режимом до 4 игроков. Проект начинался как Python/Pygame-игра с акцентом на процедурную генерацию всей графики и звука, а сейчас портируется на C#/MonoGame для лучшей производительности и кроссплатформенности.

### Ключевые особенности

- 🗺️ **Открытый мир**: стартовая деревня на карте 100×70 и 8 лесных биомов
- 🏰 **Процедурное подземелье**: 20 этажей с 4 боссами
- ⚔️ **4 класса** с развилками и сменой класса на 5 и 15 уровнях
- 🌳 **Древо навыков**: до 12 узлов, перки-книги, статус-эффекты
- 🎨 **Процедурная графика**: тайлы 64×64 и спрайты генерируются кодом (опционально — PNG-ассеты)
- 🌐 **Кооператив**: до 4 игроков по локальной сети с авторитетным сервером
- 🔊 **Процедурный звук**: синтез музыки и эффектов в рантайме

## 📂 Структура проекта
├── Core/ # Ядро правил: мир, подземелья, генерация, сохранения
│ ├── Rules.cs # Игровые правила и константы
│ ├── SkillTree.cs # Древо навыков
│ ├── DungeonGen.cs # Процедурная генерация подземелий
│ └── World.cs # Модель мира
├── Game/ # Игровые механики: бой, инвентарь, классы, квесты
├── Render/ # Отрисовка: тайлы, спрайты, свет, интерфейс
├── Net/ # Сетевой код для кооператива (в разработке)
├── Audio/ # Синтез и воспроизведение звуков
├── Content/ # Ассеты и Content.mgcb (если используются)
├── Tests/ # Модульные тесты (xUnit)
├── Program.cs # Точка входа
├── Game1.cs # Главный игровой класс (MonoGame)
└── Aethelgard.csproj

## 🚀 Начало работы

- [.NET SDK 8.0+]
- [MonoGame 3.8.2+]
- Visual Studio 2022 / Rider / VS Code (с расширением C# Dev Kit)
- Для шаблонов MonoGame в VS:
  ```bash
  dotnet new install MonoGame.Templates.CSharp

  # Клонирование
    git clone https://github.com/Valerka3421/rpg.git
    cd rpg

    # Восстановление зависимостей
    dotnet restore

    # Сборка
    dotnet build -c Release

    # Запуск
    dotnet run
