# Этельгард (Aethelgard) — 0.3.0

Тайловая RPG с процедурной генерацией на C# / MonoGame (.NET 8). Переработанная
версия [оригинального репозитория](https://github.com/Valerka3421/rpg.git)
с многослойной архитектурой — описание в [ARCHITECTURE.md](ARCHITECTURE.md).

## Ключевые особенности

- Открытый мир: деревня на карте 140×70 и 8 лесных биомов
- Процедурное подземелье: 20 этажей, боссы на 5/10/15/20
- 42 класса с повышениями на 5 и 15 уровнях
- Древо навыков, крафт-ветки, статус-эффекты
- Кооператив до 4 игроков по локальной сети с контентом сингла
  (инвентарь, характеристики, навыки, квесты, магазин, дуэли, обмен)
- Процедурная графика и звук (без content pipeline)
- Игровые данные — в классах C# (`Data/*Defs.cs`, `Entities/Monsters/*.cs`),
  редактируются прямо в коде; JSON остался только для сейвов

## Управление

### Синглплеер
- WASD/стрелки — движение, Space — атака
- F — лестницы/выход/ворота, E — добыча ресурсов, T — разговор с NPC
- I — инвентарь (1–8 — использовать/экипировать, Shift+1–8 — хотбар,
  U/V/H/B/N — снять шмотки), C — характеристики (1–6), N — навыки
  (1–7 — учить), L — квесты, B — большая карта, K — крафт, Esc — пауза
- H — быстрое зелье, F5/F9 — быстрый сейв/лоад, F12 или ` — дев-консоль

### Мультиплеер (те же клавиши, что в сингле)
- WASD/стрелки — движение, Space — атака, F — лестницы, E — добыча,
  T — разговор с NPC, H — зелье
- I/C/N/L/B — панели инвентаря/характеристик/навыков/квестов/магазина
  (раскладка совпадает с синглом)
- P — повышение класса, X — пропуск хода, Z — вызов на дуэль,
  1–8 — хотбар, Y или Enter — чат, F5 — сохранение мира (хост)

## Архитектура

Ядро (BaseClass/Entities/Structs/Data/World/Systems/Net) живёт в
`Unity/Assets/Scripts/Core/` и линкуется в MonoGame-сборку (двойная
компиляция desktop + Unity). Подробности — [ARCHITECTURE.md](ARCHITECTURE.md).

| Слой | Каталог | Содержимое |
|---|---|---|
| Ядро | `Unity/Assets/Scripts/Core/` | BaseClass/Entities/Structs/Data/World/Systems/Net (общие для desktop и Unity) |
| Хост desktop | `Desktop/` | `AethelgardGame` — цикл MonoGame, режимы экранов |
| Desktop-слой | `Systems/`, `Render/`, `Audio/` | GameController (partial), экраны UiKit, процедурный звук |
| Unity-слой | `Unity/Assets/Scripts/Game/` | GameApp/WorldView/Hud, uGUI-экраны (UiKitCanvas), MP-меню, чат, звук |

## Сборка и запуск

```bash
dotnet build Aethelgard.sln -c Release
dotnet run --project Aethelgard.csproj
```

Требуется .NET SDK 8.0+. Каталог сейвов/настроек можно переопределить:
`ETHELGARD_DATA_DIR=/путь/к/каталогу`.

## Тесты и CI

```bash
dotnet test Aethelgard.sln -c Release
```

38 xUnit-тестов (включая валидатор ссылочной целостности данных) проверяют сохранения и `FloorData`, сетевой протокол и HMAC,
PBKDF2-пароли, эффекты классов/узлов, детерминизм генерации мира и общую
симуляцию SP/MP (создание персонажа, бой, магазин, статы, навыки).

## Unity-версия

Параллельная сборка под Unity 6000.x — проект `Unity/` (открывается через
Unity Hub). Тот же геймплей: uGUI-экраны (инвентарь/навыки/крафт/
характеристики/квесты/магазин/диалоги), процедурный звук, сейвы в
`Application.persistentDataPath`, кооператив по LAN с чатом. Детали —
раздел 20 [ARCHITECTURE.md](ARCHITECTURE.md).

## Пароли

Дев-консоль и MP-сервер не хранят пароль в открытом виде: используется
PBKDF2-HMAC-SHA256 (210 000 итераций, случайная соль) и constant-time
проверка. Для дев-консоли задайте готовый хеш
`ETHELGARD_DEV_PASSWORD_HASH=pbkdf2_sha256$...`; legacy-переменная
`ETHELGARD_DEV_PASSWORD` поддерживается, но хешируется только в памяти при
старте. `GameServer.ServerPassword` принимает открытый пароль и сразу
превращает его в хеш.
