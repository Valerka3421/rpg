# Этельгард — Unity-версия

Порт игры с MonoGame (а изначально с Python/pygame, ветка `python-final`)
на Unity 6000.3.29f1. Старый MonoGame-проект остаётся в корне репозитория
для сравнения; Unity-проект полностью самодостаточен.

**Визуальный стиль = точная копия `python-final`**: палитра Stoneshards
(`render/theme.py`) в `UITheme.cs` 1:1 (панели (30,26,21), бронза
(78,66,48), золото (206,166,82), Consolas 40/22/18/14/12), кнопки-градиенты
с золотой рамкой и стрелкой, анимированный ландшафт меню с угольками,
гексагональное дерево навыков, биомные палитры тайлов, холодный свет теней
(`apply_light`), градация спрайтов (`stoneshard_grade`) и тьма с радиальной
дырой — всё портировано из Python-рендера.

## Запуск

1. Открыть `AethelgardUnity` в Unity Hub (Unity 6000.3.29f1).
2. Открыть сцену по умолчанию и нажать **Play** — вся игра собирается сама
   (`GameLoop.Bootstrap`, сцена не нужна).

Или через CLI: `Unity.exe -projectPath <путь> -batchmode ...`

## Структура

```
Assets/Aethelgard/
  Core/                 # чистая логика БЕЗ UnityEngine (asmdef Aethelgard.Core)
    BaseClass/ Entities/ Structs/ World/ Systems/ Data/ Net/
    Shim/               # шимы XNA (Color, KeyboardState) — логика переехала без правок
  Game/                 # Unity-слой (asmdef Aethelgard.Game)
    Runtime/            # GameLoop, WorldRenderer, UnityInput, TextureGen (PixelCanvas/TileRenderer/SpriteStore/MapPalette)
    UI/                 # uGUI: UIManager + все экраны
    Audio/              # AudioSystem (процедурный синтез → AudioClip)
    Editor/             # меню Aethelgard в редакторе
  Prefabs/UI/           # префабы виджетов (Generate UI Prefabs)
  Resources/            # UITheme.asset, иконки навыков
  Tests/                # порт CoreTests (NUnit, EditMode)
```

## Редактирование интерфейса из Unity Editor (без кода)

**Главный инструмент: меню `Aethelgard → Edit Interface`.**
Открывается окно «Интерфейс Этельгарда»:

1. Сверху — выпадающий список экранов (Menu, Pause, ClassSelect, Hud,
   Inventory, Shop, Skills, Craft, Stats, Quests, Dialogue, Bigmap,
   Console, Mp, Death, Message).
2. Слева — список элементов экрана (кнопки, тексты, панели, ячейки) с
   отступами иерархии; тип элемента виден сразу.
3. Справа — поля выбранного элемента:
   - **Позиция (X, Y)** и **Размер (W, H)** — в пикселях макета 1920×1080;
   - **Текст** и **Размер шрифта** (для текстов и кнопок);
   - чекбокс **«Текст из макета (!)»** — включи для статических кнопок и
     подписей, чтобы их текст брался из макета, а не из кода игры
     (динамические значения — HP, золото, предметы — всегда из игры);
4. Для серий одинаковых элементов (ячейки инвентаря `Slot0…31`, строки
   квестов, рецепты, пипсы навыков) — блок **«Серия / сетка»**: задай
   шаг X и Y и кнопкой «Расставить всю серию» выровняй всё сразу.
5. **💾 Сохранить в префаб** — правки записываются в
   `Resources/Screens/<Экран>.prefab` и **автоматически применяются
   игрой** (в том числе в уже запущенном exe после перезапуска).

Дополнительно:
- `Aethelgard → Preview Screen → <имя>` — открывает экран в иерархии
  сцены для визуальной правки мышью (Rect Tool); затем
  `Aethelgard → Apply Changes To Prefab` сохраняет результат.
- `Aethelgard → Generate Screen Prefabs` — пересоздаёт все префабы
  экранов из кода (если структура экранов изменилась; правки в
  существующих префабах будут перезаписаны).
- `Aethelgard → Create UI Theme Asset` — глобальная тема: цвета, шрифты,
  высота кнопок, отступы — всё в инспекторе, применяется ко всему UI.
- `Aethelgard → Generate UI Prefabs` — префабы отдельных виджетов.

## Паритет с python-final

Меню — точная структура `game/menu_controller.py`:
- **Главное меню (6 пунктов)**: Начать игру · Загрузить игру · Мультиплеер ·
  Настройки · **Создатели** · Выйти; кнопка «←» и Esc — на уровень вверх;
- **Настройки (6 строк)**: Разрешение · Полный экран · Звук · FPS ·
  Мини-карта · **Управление** (вкладка «Управление» живёт внутри настроек,
  как в python-final);
- **Управление** — две колонки секций (Движение / Окна / Карта и бой /
  Прочее) 1:1 из `menu_renderer.draw_controls`;
- **Создатели** — содержимое 1:1 из `menu_renderer.draw_credits`
  (команда EVA, художник «Лизабет еБатори»);
- Пауза: Вернуться в игру · Сохранить игру · Загрузить игру · Настройки ·
  Выйти в главное меню; FPS и мини-карта переключаются в настройках
  (`Settings.ShowFps` / `ShowMinimap`).

Перенесено 1:1: **система локаций** (деревня 100×70 — исторический размер,
12 локаций 120×70 в сетке 4×4: 8 биомов, Деревня гоблинов, Заброшенная
шахта, Старое кладбище, Руины города; каменные врата между ними со
сторонами света, точки появления из перехода, карты кэшируются), город с
домами/колодцем/прилавками/статуями/факелами/стражниками в воротах, выбор
класса (42 класса, 3 ступени, переход на 5/15), инвентарь (страницы 10×10,
экипировка, тултипы), магазин (покупка/продажа/реролл), крафт с минигеймом
молота, доска заданий, диалоги NPC, большая карта, дев-консоль (F12),
мультиплеер (TCP-сервер, пароль, чат, трейд), статистика забега,
**экраны смерти/победы**, 4 босса, harvest, процедурные тайлы/спрайты/звуки.
Кэш локаций в сейв не пишется — при загрузке локации генерируются заново
(сид стабильный, раскладка воспроизводима).

## Дерево навыков

Улучшено относительно MonoGame-версии:
- узлы с PNG-иконками (`Resources/SkillIcons/Class/<класс>_<n>.png`);
- три состояния: изучен (рамка цвета класса) / доступен (золотая рамка) /
  заблокирован (затемнение), подписи «ур. N»;
- линии-связи между узлами, светящиеся при изучении пути;
- тултипы с эффектами и подсказкой действия;
- бейдж доступных очков, панель перехода на новый класс;
- ремесленные ветки — 25 пипсов уровней, XP-бар, разблокировка рецептов.

## Структура проекта

```
AethelgardUnity/
  Assets/Aethelgard/     # весь код игры (см. раздел «Структура» выше)
  Assets/Scenes/Empty.unity   # пустая сцена — игра собирается сама (Bootstrap)
  Assets/csc.rsp         # -langversion:10.0 (код совместим и с C# 9)
  Packages/manifest.json # com.unity.ugui, test-framework
  ProjectSettings/       # 6000.3.29f1, окно по умолчанию 1920×1080
  Build/Aethelgard.exe   # собранная игра (в git не входит)
```

Заметки для разработчиков (все проверены на практике):
- GUI-редактор игнорирует `Assets/csc.rsp` — код должен компилироваться
  и в C# 9 (без file-scoped namespace, global using, record struct,
  field-initializer у структур);
- перед `Generate Screen Prefabs` удалять `Resources/Screens/*.prefab`
  (генератор накладывает старые префабы на новую разметку);
- спрайты мира: pixelsPerUnit = 1 (1px = 1 мировая единица).
